How it connects

Simple integration architecture

1
Authorize the store

Create read/write REST API keys in WooCommerce. Only use permissions appropriate to your demo.

2
Sync customer & order data

The backend imports up to 100 customers and 100 orders per sync through the WooCommerce REST API.

3
Receive store events

Configure a WooCommerce webhook to post order events to this endpoint:

http://127.0.0.1:5000/api/webhook/woocommerce
4
Act on customer context

View profiles, update order status and test the workflow event log in one workspace.

Local webhook limitationWooCommerce cannot reach 127.0.0.1 over the internet. Use a permitted HTTPS tunnel or deployed HTTPS host for webhook testing.
